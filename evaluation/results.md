# Evaluation results

Two layers are evaluated:

1. **API / guardrail checks (automated).** `npm run eval` starts the backend and runs every scenario in
   [test-cases.md](test-cases.md) against the real endpoints the Sarvam agent calls. These prove that the
   safety rules hold even if the LLM misbehaves (for example, the server rejects OTPs and refuses to debit
   twice).
2. **Live Sarvam test calls (manual).** The same scenarios are played as a caller against the deployed
   Sarvam agent. They check that the agent *says* the right thing and calls the right tool.
